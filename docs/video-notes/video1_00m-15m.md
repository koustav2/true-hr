## Requirements takeaways from this segment
1. NFA (Note For Approval) module with two request types: **Expense** and **Purchase Request**.
2. Cascading master-data dropdowns: Business Operation → (filters) Project list and Expense Category list; Cost to Company (12 legal entities); Cost Approval Zone (Corporate/North Star/South-East/North-West); Location master (incl. "Client-Side"); Client/Vendor unified master (very large, needs search & dedup).
3. Expense metadata: Month (Jan–Dec), Payment Type (Advance for self / Advance for Vendor / Reimbursement for self / Reimbursement for Vendor / PPS for Candidate / Incentive Payment), Billable Type (Non-billable from client / Billable from client / Billable from Partner), Settlement Date (auto-default ~1 week out, editable date field).
4. Auto-derived, read-only 4-level approval chain shown on the form: Reporting Manager, Project Leader, Finance, Business Leader.
5. Line items via "Add Headers": Expense Header + Sub Header dropdowns + NFA Amount; Excel/CSV template downloadable ("Download Expense Header").
6. All key fields mandatory (red asterisks).
7. Reference-app pain points observed: full-page "Please wait" blocking spinners after selections, slow page loads/blank screens, duplicate vendor master entries, "testing" junk data, typo "Bussiness Leader" — opportunities to improve in the new build.
