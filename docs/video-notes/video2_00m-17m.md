# Requirements extracted (summary for this segment)

1. **Employee self-service dashboard**: quick tiles (HR Induction, My Profile, Attendance, Leave, Support, COC/Emp. Undertaking, PMS, Feedback), quick actions (My Asset Details, Download Salary Slip, Tax Management, Business COC/Emp. Undertaking), monthly Attendance Calendar (Present / Leave-OD / Absent / Week Off / Sick Leave), 12-month Performance status strip (Good & Consistent / Average / Below Average / Not Available / Pending, with Pending-HR / Pending-RPT stage indicators), downloadable policy/format library (10 policies incl. Variable Pay, Holiday Calendar, Leave, R&R, Star of the Month form, Conveyance policies, Reimbursement Form, Longevity Award, Transfer & Deputation).
2. **HR Induction module**: onboarding welcome page, multi-language induction video selection (Choose Language + Proceed), mandatory watch-all-videos with per-video checkbox confirmation, HR contact for questions, feedback/suggestion box.
3. **PMS / KPI module (monthly cycle)**:
   - Employee creates monthly KPI (Create KPI page; Copy Previous KPI option; KRA rows with description, weightage % summing to 100 under "BUSINESS", measurement parameter bands mapping achievement % → rating 3/4/5; add/remove rows; Download KPI).
   - KPI goes to Reporting Manager for approval (Team KPI pending list; Approve KPI / Discuss / Download KPI actions; submitted date vs approved date tracked; per-employee Profile & Location shown).
   - Employee submits monthly PMS self-assessment (Submit PMS/Edit PMS; statuses: Not Submitted → Approval Pending → Functional Approved; KPI Status: RM Approval Pending / Locked).
   - Multi-level rating chain on Final PMS Rating: Matrix Manager → Reporting Manager → Functional Manager → HR, each with PLI Rating (color-coded band dropdown), PLI %, Remarks; **system auto-bypass when a level's approver doesn't exist** ("System By-Pass Matrix Manager Not Available").
   - KRA-level scoring grid: Sub %, Measurement Parameters, Sub Goals MTD Target vs MTD Achieved, Self Rating + Self Remarks, Mgr. Rating + Mgr. Remarks.
   - Published grade system PDF: OAT-5 ≥120%, SAT-4 105–119%, AT-3 90–104%, BT-2 60–89%, SBT-1 ≤59%.
   - PMS Dashboard tiles: My Performance, Team KPI, Team PMS, Promotion Recommendation, Skill & Employment Ecosystem (Self/Manager/Functional), Team Member.
4. **NFA (Note For Approval) / advance & expense module**: Create NFA; NFA types (Advance for self, Advance for Vendor); attributes (NFA Code auto-numbered NFAyyyynnnn, Raise For=Expense, Project, Office Location, Expense Category, Priority); NFA Status (Payment Released); post-payment **Settlement workflow** (Submit Your Settlement, statuses Pending / In Progress / Close, system auto-reject + resubmit, Check/Update Settlement); document attachments (NFA Documents, Settlement Documents download); Export Excel; sub-functions: View NFA (Rpt Mgr approval), Update Settlement, Upload Rent Agreement, Vendor Registration; Agreements repository (Upload Agreement; Project, Location, Client, Start/End dates, Agreement Type, CreatedBy/On).
5. **Other sidebar modules present (not demoed in this segment)**: Self HRMIS, JustJob, eTask Manager, New NFA Link, Investment Declaration, Business COC/Undertaking, E-Resignation, Offer Request, PM Vishwakarma Reg.
