## Requirements takeaways from this segment
1. **NFA (Note For Approval) = expense/advance/purchase-request workflow** spanning an employee portal (raise + settle) and an admin PMS (approve + report + pay).
2. Create NFA drives off multiple masters: Business Operation, Cost-to-Company (group entity), Project (per entity), Expense Category → Expense Header → Sub Header (3-level Excel-managed master, downloadable from the form), Location (offices + cities + project centers), Client/Vendor, Cost Approval Zone, Month, Payment/Billable Type (Non-billable from client / Billable from client / Billable from Partner).
3. **Approval chain auto-derivation**: Reporting Manager, Project Leader, Finance, Business Leader auto-populate from project + expense category + zone; changing category resets them.
4. Each NFA can hold multiple line items (header/subheader + NFA amount + logistic amount) with computed line totals, Total NFA Amount, Total Logistic Amount, Grand Total, plus an NFA Purpose text.
5. **Settlement lifecycle**: NFA Status (e.g., Payment Released) is separate from Settlement Status (Pending / In Progress / Close); settlement has its own date (default +1 week, editable), document uploads, "Submit Your Settlement" / "Check/Update Settlement" actions, and **automatic system rejection** of stale settlements requiring resubmission.
6. **Vendor management**: vendor registration with statutory fields+docs (PAN, GST, ESIC, PF, MSMED, NSIC/SSI, support docs), vendor list, and rent/other **agreement upload** (project, location, client, type=RENT, start/end dates, scanned copy) with admin-side agreement approval (Approve Agreements) and agreement register (view/download, created-by audit columns).
7. **Admin reporting**: View NFA approval queue (filter by date/location/entity/client/status/type + search by employee/NFA code, Export Excel, "Guidelines For Financial Initiator" doc link), NFA Report, NFA Settlement report, Project Wise Expence report (category/header/subheader rollup per project/location), Client Billing Report; dashboard KPIs (Running/Completed projects, Project Leader/Business Leader counts, FY Total NFA Raised / Approved / Payment Released).
8. Masters module in admin: Location Master, Measurement Master.
9. Cross-app SSO-style link: GreenHR "New NFA Link" opens vispl.co.in/PMS/Login.aspx with token parameters.
