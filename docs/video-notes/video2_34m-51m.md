# Requirements extracted from this segment (NFA = Note For Approval / expense-advance workflow)

1. **NFA creation** (employee self-service): master-driven cascading selects — Raise For, Business Operation, Cost to Company, Project, Expense Category → Expense Header → Sub Header; Cost Approval Zone; Location; Client/Vendor; Month; Payment Type (e.g. Advance for Vendor / Advance for self / Reimbursement); Billable Type (billable / non-billable from client); Settlement Date; auto-populated approver names (Reporting Manager, Project Leader, Finance, Business Leader); multi-line amount entry (NFA Amount + Logistic Amount = Total per line) with running totals and Grand Total; NFA Purpose, NFA Description, file attachment, Priority (High/Medium/Low); system-generated NFA Code (NFA + year + seq).
2. **Expense master data** maintained as Category → Header → SubHeader hierarchy (demoed from Excel master "Expanse-Header-NFA": categories incl. General Administrative, Asset Procurement, IT Infra, IT Software, HR, Marketing & Branding, etc.).
3. **Sequential multi-stage NFA approval**: Reporting Manager → Finance Initiator → Project Leader → Business Leader → Finance → Final Approval; each stakeholder sees pending queue (filter by date range, status, location, employee code; Export Excel), opens NFA detail, and can **Approve / Query-Hold / Reject / Edit** with remarks and attachment download; status values include Pending and "Query Raised By: <role>".
4. **Approver edit rights**: Update NFA screen allows changing all header fields and line amounts with mandatory "NFA Update Remark".
5. **Employee NFA ledger**: per-FY summary — counts of NFAs raised / payments released / settled, amount received vs settlement amount vs balance to be settled (Show Ledger on approval screen).
6. **Settlement cycle**: after payment release employee must "Submit Your Settlement"; settlement statuses Pending / In Progress / Close; **auto-reject of stale settlements with resubmission**; settlement has its own approval chain (Rpt Mgr → Funct. Head → Admin → Finance → Director → Closer) tracked with approver name/status/remarks/date per stage; Approved/Rejected Settlement report filterable by year/month, Export Excel.
7. **Employee dashboard**: attendance calendar (Present/Leave-OD/Absent/Week-Off), monthly performance (PMS) status per month (Pending-HR / Pending-RPT / rating bands), quick links (salary slip download, asset details, tax management, COC/undertaking, PM Vishwakarma registration), HR induction, leave, support/helpdesk, feedback, policies & formats downloads.
8. **E-Resignation module** with three role views: self, Team (manager), Functional head — under Full & Final section.
